# lavals/homebrew-tap

Homebrew casks for [lavals](https://github.com/lavals) apps.

## Pomodoro

A menu bar pomodoro timer for macOS that turns on Focus while you work. Source: [lavals/mac-pomodoro-timer](https://github.com/lavals/mac-pomodoro-timer).

```
brew tap lavals/tap
brew install pomodoro
```

Requires macOS 14 or later on Apple Silicon.
